# Design e prototipos

Materiais visuais do app mobile ficam aqui para manter a raiz limpa.

## Conteudo

- `prontuarios-mobile-brief.md` - brief do modulo mobile de Prontuarios.
- `scandexplus-mobile-design-system/` - export visual usado como referencia
  para tokens e componentes.

## Regra de uso

O app real vive em `../src/`. Ao migrar ideias do design system, prefira
componentes nativos React Native e atualize os tokens em `src/theme/theme.ts`.
